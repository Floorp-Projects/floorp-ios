Floorp 0.3.0 — ネイティブ WebExtensions リリース候補

このビルドでは、Floorp の実験的な拡張機能ランタイムを Apple の公開
WKWebExtension API に置き換えました。任意でインストールできるアプリ同梱の
Dark Reader 4.9.129 と uBlock Origin Lite 2026.825.1619 が含まれます。
サインインは不要です。

「設定」>「拡張機能」から Dark Reader をインストールしてください。ページの外観、
アクションポップアップが動作し、遷移中に閉じても API 応答後に閉じること、無効化／アンインストールで
開いているページがすぐ元に戻ることを確認してください。再有効化と再インストールは再起動後に完了し、
状態を保持すること、ポップアップの下に無効な拡張機能ピッカーが現れないことも確認してください。
Floorp／Dark Reader を35秒以上アイドル状態にした後、新しい HTTP(S) ページへ移動し、
ポップアップや再読み込みなしで初回表示から暗くなることを確認してください。

iOS 26.0 以降では uBlock Origin Lite をインストールしてください。初回インストール、
コールド復元、再有効化では WebKit のネイティブルールセットコンパイルを最大4分待ってください。
通常／プライベート各コンテキストの初回ナビゲーションも最大90秒待機し、準備未完了なら
閉じた状態で失敗します。機密情報を含まないテストサイトで、公式ルールの対象となる
広告／トラッカーのリクエストと装飾要素が除去される
ことを確認します。ポップアップ、ダッシュボード、日本語フィルターリストの状態変更（すでに
有効な場合は一度オフにしてから再度オン）、無効化／
再起動をまたぐ有効化、アンインストール／再起動／再インストール、再起動後の状態も確認してください。
開発者モードを有効にし、通常と許可済みプライベートの両方から「一致したルール」を開き、
遷移中にも閉じ、遷移先が一度だけ開いて元のモードを維持することを確認してください。ダッシュボードの
Web リンクが Floorp のタブで開き、現在の通常／プライベートモードを維持することも確認します。
無害な user DNR を保存後に全削除し、「unknown error」が出ず、再起動後も遮断とダッシュボードが動き、
「一致したルール」に内部 keeper ID 7,000,000 が表示されないことを確認してください。
既存テスト版から更新してもルールが残り、keeper 用2枠と各 store 14,999件上限のためにルールが自動削除されないことを確認してください。
公式 Safari パッケージでは strict-block の中間画面が意図的に無効ですが、通常のリクエストブロックと
装飾フィルタリングは動作する必要があります。iOS 26.0 未満では Dark Reader は利用でき、
uBlock Origin Lite には iOS 26.0 が必要と表示されることを確認してください。

プライベートブラウジングへのアクセスは個別に許可するまでオフである必要があります。
許可前はどちらの拡張機能もプライベートタブに影響しないこと、許可後はプライベートタブ、
権限、拡張機能の状態が通常ブラウジングへ漏れないことを確認してください。

任意の ZIP、XPI、CRX、URL、拡張機能ストアからのインストール経路があってはなりません。
タブ、履歴、ダウンロード、リーダーモード、追跡防止、Notes／Sync の回帰も報告してください。
