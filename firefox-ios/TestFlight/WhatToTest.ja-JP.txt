Floorp for iOS — 拡張機能管理 UI 候補

この候補に含まれる署名済み・アプリ同梱の拡張機能は Dark Reader 1件です。通常プロファイルで
「設定」>「拡張機能」を開き、Firefox のグループ化された設定画面に沿った構成が Dynamic Type と
VoiceOver でも理解しやすいことを確認してください。Dark Reader は拡張機能に同梱されたアイコン、
名前、版、説明、および状態（利用可能／有効／無効／アップデートあり／失効）を備えた標準的な
遷移行として表示される必要があります。読み込み中、空、エラー、再試行、処理中の状態が操作可能に
見えたり、同じ処理を重複実行できたりしてはなりません。

利用可能な Dark Reader の行を押します。導入確認画面に Dark Reader のアイコンと識別情報、
公開元／入手元／ライセンス、要求機能、プライバシーとプロファイルの説明、およびサイトアクセスが
未許可から始まる注意が表示されることを確認します。一度キャンセルし、導入されていないことを
確認してください。再度開いて「インストール」を1回だけ押し、進行状況が見え、1件だけ導入される
ことを確認します。導入後はサイトアクセスを選ぶ案内付きの管理画面が開き、すべてのサイトへの
アクセスが暗黙に許可されてはなりません。

個人情報を含まない承認済み HTTP(S) ページで browser の Dark Reader action を開き、現在の
サイトだけを許可します。ページが再読み込みされ dark 表示になることを確認してください。
popup には `about:` ではなく実 hostname が表示され、通常ページを「browser によって保護」と
誤表示してはなりません。popup を開いたまま Off／On を切り替え、ページと popup の状態が毎回
更新されることを確認します。Dark Reader の Settings を押して設定を変更し、再読み込み後も
認証済み・同梱の設定ページと保存内容が正しく動作することを確認してください。

「設定」>「拡張機能」に戻って導入済み Dark Reader の行を開き、表示される管理操作を確認します。
無効／有効、オプション、通常サイトアクセス、Private Browsing の opt-in と private
サイトアクセス、network protection、Web サイト、更新履歴、アップデート（表示時）、削除を
順に試してください。各操作後にボタンと行の状態が更新され、spinner の停止、sheet の重複、
crash、古い表示がないことを確認します。無効化時は popup とページ変換が停止し、再有効化時は
generation を変えずに復元する必要があります。削除して再導入した後は、サイトアクセスが再び
未許可から始まり、削除した拡張機能所有設定が復元されてはなりません。

Private Browsing でも導入、管理、サイトアクセス、popup、Settings、削除を繰り返します。
Private 利用は opt-in かつ profile-local です。通常側の権限、storage、alarms、runtime state が
private 側へ漏れたり、private 側から通常側へ戻ったりしてはなりません。

リリース完全性: 「設定」>「拡張機能」の catalog package は1件だけである必要があります。
Chrome ウェブストア、Firefox Add-ons、任意 URL、ZIP、XPI、CRX、共有シート、ローカルファイル
からの導入経路があってはならず、Dark Reader は remote code、設定、update、filter list を取得
してはなりません。不一致、余分な項目、権限回避、想定外通信、profile 間漏えい、crash、hang、
版／ビルド不一致があれば中止・報告してください。

主要経路を英語／日本語、大きな文字、VoiceOver でも確認してください。個人の認証情報や本番
データは使わず、承認済みの非機密ページだけを使用してください。
